03 — POURQUOI ÇA PIQUE MOINS

Le rouge vif devient nuit

Le fond d'origine pose un rouge saturé sur toute la surface et une lune à 100 % de blanc : l'œil n'a nulle part où se poser le soir. Ici le ciel est de l'encre, la lune une ivoire chaude qui plafonne à 76 % de luminance, et l'orange Flow n'apparaît que sur des points : braises, holo, grille. Mesures faites sur les images réelles en 1920 × 1080 (luminance relative, image gelée à t = 14 s).

Accessible par construction. Le réglage système « réduire les animations » est respecté : une seule image, plus de rendu. « Mouvement » à 0 fait pareil à la main, pour les troubles vestibulaires ou l'attention. « Luminosité » et « Confort nuit » couvrent la photosensibilité. Les textes (heure, étiquettes) sont du DOM, pas des pixels dans le canvas : ils restent lisibles par un lecteur d'écran et nets à toute résolution.

Léger par défaut. Un seul fichier, aucune requête réseau, résolution plafonnée à 1,5×, rendu suspendu quand Lively met le fond en pause (plein écran, jeu).

05 — INSTALLATION

Cinq minutes, zéro compte

  1. Installer Lively Wallpaper (gratuit, open source ; aussi sur le Microsoft Store).
  2. Glisser Flow-Nocturne-lively.zip dans la fenêtre Lively. Le fond apparaît dans la bibliothèque.
  3. Clic sur la vignette : c'est appliqué. Clic droit → Personnaliser pour les curseurs ci-dessus.
  4. Deux écrans : onglet « Écrans » de Lively, dupliquer ou choisir une scène par écran (Uchiha au centre, Nuit Flow sur l'écran de travail, par exemple).
  5. Paramètres → Performance : « pause si application plein écran » pour ne rien perdre en jeu ou en montage.
06 — SOURCES & INSPIRATIONS

D'où ça vient

  • Marque Flow — noir #080808, orange #FF7A00, blanc #F2F2F2, Bebas Neue + DM Sans + DM Mono, logo : relevés sur flow-consulting.fr.
  • Composition — le fond Itachi fourni (lune, poteau, corbeaux vers la gauche). La silhouette est un masque alpha extrait de cette image, usage personnel ; une version vectorielle originale est prévue pour une diffusion.
  • Lively Wallpaper — API des propriétés, événements système, ligne de commande.
  • Moteur — Three.js r186 (bloom UnrealBloomPass, OutputPass ACES), esbuild. Polices Bebas Neue, DM Mono, DM Sans (OFL).
  • Naruto — le shunshin d'Itachi (le corps qui se défait en corbeaux), Amaterasu (les flammes noires, ici des braises), les trois tomoe du Sharingan en filigrane dans le halo.
  • MCU — les interfaces holographiques de l'atelier de Tony Stark (anneaux, graduations, étiquettes mono, scanlines) : scène Jarvis.
  • Pistes suivantes — Speed Force (DC : éclairs orange, traînées), Patronus (Wizarding World : volutes argentées sur encre), Konoha la nuit (lanternes, lucioles, falaise des Hokage).
07 — ET APRÈS

Un fond d'écran, c'est déjà un thème

Ce qui est livré ici n'est pas trois images : c'est un moteur et un jeu de jetons (accent, luminance, mouvement, densité, confort, éco) que chaque scène interprète. Le thème neutre est la base de travail ; les thèmes « lore » sont des peaux par-dessus, et les curseurs d'accessibilité sont les mêmes pour tous.

C'est exactement la mécanique d'une banque de thèmes pour des interfaces métier : une grammaire commune (jetons, états, contrastes, mouvement réduit, lecture d'écran), un thème neutre irréprochable, puis des peaux à l'infini, du sobre au Sharingan, sans jamais casser l'usage. La cartographie des métiers vient nourrir la couche d'en dessous : quels écrans, quels gestes, quelles données chaque savoir-faire manipule.
